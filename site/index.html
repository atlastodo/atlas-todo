Atlas Todo

An open-source to-do app with end-to-end encryption. Your tasks, notes, projects and habits are encrypted on your devices before they sync, so the server stores them but cannot read them. It works offline and syncs live between the web, Android and the Linux desktop.

Try it

  • Open the web app at app.atlastodo.dev.
  • Android: download the APK from GitHub Releases.
  • Run your own server with Docker: see the self-hosting guide.

app.atlastodo.dev is a small test server. It may be reset or go offline; keep your own backups or self-host for anything important.
